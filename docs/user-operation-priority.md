# 用户操作优先级

用户在面板中明确选择的层级，优先于自动压缩的单块预算和 Agent 的证据读取。模型上下文总容量、原会话是否仍可替换、数据一致性及破坏性操作的保护仍然有效。

## Block 层级选择

- 自动封块和衰减继续使用 `min(4096 tokens, 模型窗口的 4%)` 的单块限制。用户手动选择不使用这项限制，也不要求展开后的内容必须比原内容小。
- 已加载会话在保存选择前，估算替换后的整段会话大小，并计入已知工具定义及输出预留。预计超过模型窗口且会使占用增加时，先从最旧的自动管理历史块中逐层简略，腾够空间就停止；保留其他手动选择、当前输入和工具调用链。只替换本插件已有的历史展示片段，保留原文和恢复能力，不额外调用模型。
- 容量方案在写入前整体检查。腾出所有可用空间仍不足时，不修改任何历史展示或展开指针，就地说明当前模型预计放不下，并提供选择更简略层级或切换更大模型的下一步。缩小内容的选择仍可执行。
- 估算不是模型 tokenizer 的精确计数；模型窗口未提供时，不推测为 4096。之后宿主组装的新提示、工具变更及模型服务的实际限制仍由宿主处理。
- 用户可选择更高或更低层级，也可重新选择当前层级来替换尚未生效的旧请求。自动维护不能立即用单块限制撤销用户选择。
- 选择会重设衰减起点。新封存块继续增长后，仍按原规则自然衰减；这不是永久置顶。
- Agent 工具仍返回所请求层的证据；已有用户选择时，不改用户层级、来源或衰减起点，也不为这一只读结果生成快照。

## 同步结果

- 点击历史块只打开“分层内容预览”，预览不改变助手可见的内容；每层用“让助手参考 L4”等直接按钮应用选择。“助手可见层级”只显示已确认的实际层级，尚无确认信息时显示“尚未确认”。助手可见不表示助手已经读过或采用。
- `applied`：所选内容已写入原生会话并完成保存。直接更新实际层级，短暂显示“已应用 L4，供助手后续回复参考。”，不留下永久来源徽章。
- `pending`：选择已保存，但所属会话尚未加载、仍在整理或正在保存。对应历史块旁说明“打开这段对话后生效”等具体情况，以及助手当前仍可见的层级。
- `blocked`：会话加载后发现整体容量不足，或原片段已不可替换。对应历史块旁说明原因、当前有效层级和下一步，并记录错误；普通请求不再反复渲染该任务。请求中断、保存报错或刷新失败时，提示暂时无法确认结果，标明上次确认的层级，并提供“刷新状态”，不谎报应用失败。

正常操作不因插件的内部阈值弹出二次确认。涉及新的费用或授权、破坏性操作、改变其他手动选择时，才让用户作出实质决定。主流程使用用户熟悉的说法，技术细节按需展开。

容量阻塞会在模型路由容量、工具定义或输出预留变化，以及宿主整理后重新检查；相同请求头不会触发无效重试。用户重新选择会立即重新检查。来源片段不可替换时，保留明确失败状态，不自动复活宿主已压缩掉的内容。

原生会话日志与记忆库不是同一个事务。保存中途失败会返回错误并保留同步请求；重试以实际上下文为准，避免重复插入。重启后从用户锚点与实际层级重建未完成选择，包括向较低层级的切换。

## 本次相邻排查范围

除手动展开外，检查了画像编辑与后台整理、事件置顶与自动去重、手动重试、去重人工选择与撤销附近的优先级保护。

- 画像整理在写入前比较完整输入快照；较早的后台结果不能覆盖用户刚改的画像，受保护短字段不能被整理改写。
- 置顶事件有权重及去重保护，人工去重结果不会被普通重扫清除。
- 手动重试可重设已耗尽的自动重试次数。主题整理的手动重试有一次优先尝试，不等待自动历史补建额度；该权限在认领任务时原子消费，重启不丢失，也不会被失败后的自动重试反复使用。用户明确暂停或禁用的功能仍保持暂停或禁用。
- 合并、归档、撤销等涉及持久数据的操作继续检查来源、并发修改及撤销条件，不因“用户优先”跳过一致性保护。

此范围不是全仓库所有用户操作的穷举审计，也不扩大任何破坏性操作的授权。
