# 可选知识图谱（第一阶段）

知识图谱默认关闭。事件卡、主题目录、普通记忆检索和常驻 Profile 独立工作；关闭图谱不会删除已有节点、边、来源、事件或处理记录，也不会重新提取事件或重建目录。

## 使用方式

在记忆界面的 **更多 → 高级设置 → 记忆配置 → 启用知识图谱** 操作。

- 新安装默认隐藏长期记忆中的图谱页；开启后显示，曾经开启后关闭仍保留入口。
- 已有数据库升级默认关闭，保留入口并将图谱内容置灰；首次进入设置显示说明，点击“我知道了”后持久记录，不再显示。
- 图谱与事件卡、目录存在部分重复。开启会额外调用模型整理实体和关系，后续维护、补建和自动注入也会增加 token 消耗；可随时关闭或重新开启。
- 开启和继续先统计各空间尚未完成的事件。存在待处理事件时，显示数量和预计批次数，用户确认后才启用。没有待处理事件时直接恢复查询和展示。
- 确认只批准统计时的有限事件 ID 清单，不在每次启动时自动扩展历史范围。此前代次的排队任务（包括没有创建代次的旧任务）只能处理本次批准的有效来源；批次内未批准、已遗忘或已归档的事件不会送入模型。正常启用期间产生的新事件沿用原有增量投影，无须第二次审批。每批最多 8 条，每轮处理一批，沿用现有租约、并发竞争、退避和最多 3 次尝试限制；手动重试才另开尝试预算。
- “暂停图谱任务”暂停投影和补建，保留查询；“统计并继续图谱任务”重新统计和确认。关闭开关同时停用图谱查询和自动注入。

## 持久化与迁移

DSH 使用数据库内既有 `stratagate_dsh_settings`：`graphEnabled` 保存用户选择，`graphControl` 保存暂停、控制代次、首次说明状态和有限补建清单；`graphPolicyMigration` 标记一次性初始化。首次缺少开关时写入 `false`；已有明确值保持不变。只读浏览旧库不触发写入迁移，首次设置操作或正常写入启动时完成初始化。

Core 为 `memory_spaces` 添加 `graph_enabled`、`graph_epoch`，以 `stratagate_graph_policy_migrations` 标记兼容迁移，保留当前 schema 版本和旧数据结构。SDK 默认同样关闭，可用 `graphEnabled: true` 显式创建开启的新空间；打开已有空间尊重持久状态。对已有空间先读取 `graphBackfillEventIds()`，用户确认后调用 `setGraphEnabled(true, approvedIds)`，不自动补建未批准历史。DSH 的安装级设置优先于 Core 空间配置。

SDK 的有限批准清单复用 `memory_spaces` 配置行，兼容增加 `graph_approved_event_ids_json` 文本列保存；缺失时按空清单读取，writer 首次打开时添加列，不改变 schema 版本或既有图谱内容。任务 JSON 的可选 `createdEpoch` 仅用于区分本代次新增任务与历史任务；缺少该字段不会获得自动处理权限。调度索引升级规则版本后按相同来源过滤规则重建，避免后台重复发现不可执行任务。

## 关闭时的运行时边界

关闭会阻止新投影入队、历史补建、后台图谱调度、过期任务恢复、自动和手动重试、自动图谱召回及上下文注入。普通 Agent 不再注册 `memory_search_graph`、`memory_expand_graph_node`、历史 `memory_expand_element`；已取得的工具引用也会再次检查状态。管理员仍可读取保留的数据用于灰色展示。

每次关闭或暂停递增控制代次。领取任务、模型请求及其内部格式重试检查代次；完成、失败和租约续期也检查。每次领取还生成独立的持久化 `claimToken`，所以租约过期后同一任务 ID 的新 attempt 不会接受旧请求的迟到结果。SQLite 在写事务内再次核验，拒绝关闭期间、旧代次或旧 attempt 的迟到结果。并发事件提取仍可提交事实，但提交时会剔除新产生的图谱排队任务。重新确认恢复时使用新的任务 ID，保留已消耗的尝试次数；已耗尽三次尝试的旧代次任务保持失败终态，不会复制成不可执行的 `pending` 任务，旧请求也不能覆盖新任务。

恢复不会清空既有终态错误或隐式重置次数；已存在的错误 `pending + attempts>=3` 记录会收敛为明确失败。显式手动重试仍沿用原有入口并开启新预算，每次重试都创建新的任务 ID（同一代次也如此），旧失败记录保留审计信息。`memory_assess.next_strategy` 与 Graph 工具一起动态更新，关闭时不再提示图谱检索或历史 Element 工具。

已经发给供应商的请求无法保证撤回，其剩余 token 可能仍计费；此结果不会写回图谱，也不会继续发起内部重试。

## 降级限制

旧版本不认识 `graphEnabled` 及控制代次。数据库仍可被旧版本打开，但降级运行可能重新启用图谱处理、补建、工具和自动注入，也无法保证拦截迟到结果。关闭状态的运行时保证仅适用于支持此开关的版本；不要同时运行新旧版本写入同一数据库。

本阶段不增加每日 MD，不改变事件卡提取、目录生成更新或 Dreaming 职责。
